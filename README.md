### ✨ Addons de Creación Propia
- **LoboExporter**: AddOn complejo con interfaz (pestañas y progreso) creado para extraer, organizar y mantener un seguimiento íntegro de la base de datos de botín (BiS), logros, monturas, personajes y más.

- **ChatFontFix**: Un módulo hecho a medida para evitar y parchear bugs molestos relacionados con las fuentes de texto nativas en el chat del juego.

### 🛠️ Addons Modificados y Parcheados

- **Oilvl**: Parches de compatibilidad para asegurar el correcto escaneo de equipo en bandas.

### ✨ Custom Created Addons
- **LoboExporter**: A complex addon with a custom UI (tabs and progress tracking) built to extract, organize, and track a comprehensive database of loot (BiS), achievements, mounts, characters, and more.
- **WoWDiscordRPC**: A custom-built telemetry bridge that broadcasts the player's status through a pixel-rendering system for Discord Rich Presence, without requiring memory injection.
- **ChatFontFix**: A custom module designed to prevent and patch annoying bugs related to native text fonts in the game's chat.

### 🛠️ Modified and Patched Addons
- **World Quest Tracker**: Adjustments to the flight map to force visual hiding of quests.
- **Legendary Progress Tracker**: Integration with Broken Isles rares and autosave functionality.
- **Oilvl**: Compatibility patches to ensure proper gear scanning in raids.
- *(And dozens of other minor patches and improvements in addons like DBM, ElvUI, etc., to avoid bugs in version 7.3.5)*
